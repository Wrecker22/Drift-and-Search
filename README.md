The intent of this project is to create the means to determine where an object/person is in the water after the passing of an amount of time
it takes the Last Known Position and adds the effect of Wind and Current to calculate the Most Probably Position
Project started in Excel, where all the calculations were made.
The aim changed to have the output of the calculator produce a plot on a chart and show the area to be searched
transferring the coordinates from excel to a HTML chart required enabling macros of excel.  This was not acceptable.
The excel calculator was merged into the html charting tool to make a single file  which works fine on Windows computers
The advice was to lodge this completed html on github and send out a https; link to the users
